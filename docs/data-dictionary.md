# Data Dictionary

All tables are synthetic, generated by `engine/generate_data.py` with a fixed seed. Raw tables live in `data/raw/` and are loaded into `warehouse/trialflow.db`. SDTM-style domains are written to `sdtm/`.

## Raw EDC tables

### sites.csv
| Column | Type | Description |
|---|---|---|
| site_id | int | Site number, 101 upward |
| country | str | Site country |
| pi_name | str | Principal investigator (synthetic) |
| monitor | str | Assigned CRA code |
| target_enrollment | int | Enrolment target for the site |
| activation_date | date | Site activation date; null if never activated |
| status | str | Active or Planned |

### subjects.csv
| Column | Type | Description |
|---|---|---|
| usubjid | str | Unique subject id, `TF-201-<site>-<nnn>` |
| site_id | int | Enrolling site |
| country | str | Site country |
| arm | str | TF-Compound 150mg or Placebo |
| sex | str | F or M |
| age | int | Age in years at enrolment |
| enrollment_date | date | Randomisation / enrolment date |
| status | str | Active, Completed, Withdrawn, Screen Failure |
| disposition | str | Free-text disposition reason |
| pregnancy_status | str | Negative / Not applicable (used by the cross-form check) |

### visits.csv
| Column | Type | Description |
|---|---|---|
| usubjid | str | Subject |
| site_id | int | Site |
| visitnum | int | Visit number, 1&ndash;6 |
| visit | str | Screening, Baseline, Week 4/8/12, Week 16 EOT |
| scheduled_date | date | Protocol-derived due date |
| actual_date | date | Date the visit occurred; null if Missed or Pending |
| status | str | Done, Missed, Pending |
| win_lo / win_hi | int | Allowed window offsets (days) around the due date |
| target_day | int | Protocol target day from randomisation |

### forms.csv
Rows exist only for visits with status Done (an EDC holds CRF pages only for visits that occurred).
| Column | Type | Description |
|---|---|---|
| usubjid, site_id, visitnum, visit | | Visit key |
| form_name | str | Required CRF for that visit |
| completed | int | 1 if entered, 0 if missing (feeds the missing-data check) |
| entered_date | date | Data entry date; null if not entered |

### labs.csv
Vital signs and laboratory results for visits with a Laboratory or Vital Signs form.
| Column | Type | Description |
|---|---|---|
| usubjid, site_id, visitnum, visit | | Visit key |
| testcd | str | SYSBP, DIABP, PULSE, ALT, HGB |
| result | float | Recorded value |
| unit | str | Result unit |
| result_date | date | Result date (before screening in a small number of rows, on purpose) |
| ref_lo / ref_hi | float | Reference range bounds for the out-of-range check |

### adverse_events.csv
| Column | Type | Description |
|---|---|---|
| usubjid, site_id | | Subject and site |
| aeseq | int | Sequence number |
| aeterm | str | Reported term |
| aebodsys | str | System organ class |
| aesev | str | Mild, Moderate, Severe |
| aeser | str | Y / N serious |
| aerel | str | Not related, Unlikely, Possible, Probable |
| aestdtc / aeendtc | date | Start / end date; end null if ongoing |
| aeout | str | Outcome |
| arm | str | Treatment arm |

### deviations.csv
| Column | Type | Description |
|---|---|---|
| usubjid, site_id, visitnum, visit | | Deviation location |
| dvterm | str | Deviation description |
| dvcat | str | Minor, Moderate, Major |
| dvdtc | date | Deviation date |
| dvstatus | str | Open or Closed |
| corrective_action | str | CAPA text |

### queries.csv
| Column | Type | Description |
|---|---|---|
| query_id | str | `Q-nnnn` |
| usubjid, site_id, form, field | | Query location |
| reason_code / reason_text | str | Query reason |
| severity | str | Minor, Moderate, Major |
| status | str | Open, Answered, Closed |
| opened_date | date | Date raised |
| age_days | int | Age at data cut |

## SDTM-style domains (`sdtm/`)

Simplified demonstration model using SDTM Implementation Guide variable names. Not a validated implementation.

| Domain | Key variables |
|---|---|
| **DM** | STUDYID, DOMAIN, USUBJID, SUBJID, SITEID, RFSTDTC, AGE, AGEU, SEX, COUNTRY, ARM, ARMCD, ACTARM, DSDECOD |
| **AE** | STUDYID, DOMAIN, USUBJID, AESEQ, AETERM, AEBODSYS, AESEV, AESER, AEREL, AESTDTC, AEENDTC, AEOUT |
| **VS** | STUDYID, DOMAIN, USUBJID, VSTESTCD, VSTEST, VISITNUM, VISIT, VSORRES, VSORRESU, VSDTC |
| **SV** | STUDYID, DOMAIN, USUBJID, VISITNUM, VISIT, SVSTDTC, SVENDTC |
